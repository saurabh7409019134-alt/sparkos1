## 19. Smooth Animations — Important

Add subtle, high-quality animations that make the website feel polished without distracting visitors.

Animations must support the design, not dominate it.

A. Hero entrance (on initial page load): headline fades in and moves upward slightly; supporting text appears shortly afterward; CTA buttons fade in with a small delay; hero visual elements appear with gentle staggered motion. Use approximately 400–800 ms for the main entrance transitions. Avoid dramatic zooms or long intro sequences.

B. Hero visual animation: floating content cards move gently by a few pixels; blue light trails move slowly and smoothly; the automation workflow card runs a subtle six-second loop; workflow nodes illuminate sequentially; a cyan pulse travels along connection lines; a completion checkmark appears briefly before the animation resets. Keep the motion subtle and avoid continuous rapid movement.

C. Scroll reveal: gentle fade-up animations as sections enter the viewport. Trigger once when practical. Keep the movement small. Avoid hiding important content if JavaScript fails. Avoid animating every individual text line unnecessarily.

D. Service cards (hover): slightly brighten the border; increase the blue/cyan glow subtly; move the card upward by only a few pixels; transition smoothly back. The primary Content & Growth card should have a restrained accent glow.

E. Buttons: smooth color transitions; subtle brightness changes on hover; a small arrow movement where appropriate; clear keyboard-focus indicators. Do not make buttons bounce or pulse continuously.

F. Workflow timeline: animate the connecting line or active step subtly when the section becomes visible.

G. Portfolio cards: gentle image zoom on hover, with the text and card dimensions remaining stable.

H. Navigation: smooth scrolling and restrained active-link transitions.

Animation implementation: use CSS transitions and keyframes for simple animations; use an existing animation library only if it is already available and suitable; use Intersection Observer for scroll-triggered effects; avoid unnecessary JavaScript animation loops; animate transform and opacity wherever practical; respect prefers-reduced-motion; keep the website responsive and performant on mobile devices; ensure animations never prevent visitors from clicking, reading, or navigating.

## 20. Responsive Design

Desktop: wide content container; balanced hero layout; four service cards where space permits; clear section separation.

Tablet: adjust card grids and heading sizes; maintain readable spacing; avoid horizontal overflow.

Mobile: single-column content where appropriate; readable headings and body text; full-width CTA buttons where useful; stacked pricing cards; a working mobile navigation menu; simplified hero artwork and animations; properly sized touch targets.

Test the layout at approximately 375 px, 768 px, 1024 px, and 1440 px widths.

Step 3 — Build: implement the full page, all sections, pricing, portfolio examples, inquiry form, and responsive navigation.
Step 4 — Animate: add the subtle animations described above without changing the brand identity or disrupting the layout.
Step 5 — Test: run the application and check desktop layout, mobile layout, navigation, smooth scrolling, service links, pricing cards, portfolio filters, FAQ accordion, inquiry form validation, animation performance, console errors, broken images and links.
Step 6 — Refine: fix visible layout issues, inconsistent spacing, excessive glow, unreadable text, and broken interactions.
